803 材料科学基础 · 知识库问答网页 —— 使用说明
================================================

这个文件夹（qa-app）里就是整套网页的全部代码和知识库，可以拷到任意一台电脑上运行。

一、在自己电脑上打开网页（自己用）
----------------------------------
1. 安装 Python：打开 https://www.python.org/downloads/ 下载安装，
   安装时务必勾选底部的 "Add Python to PATH"。
2. 双击本文件夹里的「启动网页.bat」，等它自动装依赖、启动。
   （也可以手动在命令行跑：pip install -r requirements.txt  然后  streamlit run app.py）
3. 浏览器会自动打开 http://localhost:8501 就能用了。
   API Key 在网页左侧「高级设置」里填（DeepSeek / Claude / 图片识别）。

二、让别人也能访问（公开链接）
------------------------------
方法 A：永久在线（推荐，但需要 GitHub 账号 + 能上 Google 的网络/VPN）
  1. 注册 GitHub（注册页的人机验证是 Google 提供的，需能访问 Google）。
  2. 把本文件夹推到 GitHub，再用 share.streamlit.io 一键部署。
  3. 部署完成后得到一个固定网址，谁都能随时打开，不依赖你的电脑。

方法 B：当天应急（不用 GitHub，但需电脑一直开着）
  1. 到 https://www.cpolar.com 注册并下载安装 cpolar。
  2. 在命令行执行：
        cpolar authtoken 你的token
        cpolar http 8501
  3. 会得到一个形如 https://xxxx.cpolar.top 的网址，发给别人即可访问。
     注意：免费版网址每次重启会变；电脑关机就断。

三、注意
--------
- 网页功能：知识地图、3D 晶体结构、智能问答、图片 OCR、闯关练习、学习记录。
- 知识库在 kb/ 文件夹（10 个 .md 文件），以后改知识库直接编辑这些文件即可。
- 智能问答和图片 OCR 需要填 API Key，不填也能用知识地图/闯关练习/学习记录。
