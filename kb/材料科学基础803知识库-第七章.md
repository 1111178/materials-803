# 第七章 二元系相图及其合金的凝固

---

## 相图的基本知识与相律
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
**相图（平衡图）**是表示合金在平衡条件下，温度、成分与相之间关系的图。二元相图以温度为纵轴、组元成分为横轴。

**相律**给出平衡系统中自由度 f、组元数 C、相数 P 的关系：

**f = C − P + 2**（恒压时为 **f = C − P + 1**）

对二元系（C = 2），恒压时 f = 3 − P：

- **单相区**：P = 1，f = 2，温度和成分可独立变化（是"区"）。
- **两相区**：P = 2，f = 1，温度和成分中只有一个独立（由杠杆定律定两相相对量）。
- **三相平衡**：P = 3，f = 0，在恒温下进行（是"水平线"），如共晶线、共析线。

相图中几条重要线：**液相线**（以上全为液相）、**固相线**（以下全为固相）。两相区中相的成分由**等温线（结线）**与相界线交点确定。

### 例题
二元合金处于两相平衡区时，其自由度是多少？温度和成分能否同时独立变化？

**答案**：恒压下 f = 3 − P = 3 − 2 = 1，自由度是 1。两相平衡时温度与两相成分中只有一个独立变量，温度定了两相成分就定，不能同时独立变化。

## 杠杆定律
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
**杠杆定律**用于计算两相区中两相的**相对量（质量分数）**。设合金总成分为 C₀，处于两相区，两相成分分别为 C₁ 和 C₂（C₁ < C₀ < C₂），则两相质量分数 W₁、W₂ 满足：

**W₁ / W₂ = (C₂ − C₀) / (C₀ − C₁)**

即：

**W₁ = (C₂ − C₀) / (C₂ − C₁)**，**W₂ = (C₀ − C₁) / (C₂ − C₁)**

其几何意义是：以合金成分点 C₀ 为支点，两相的相对量与其到成分点的**距离成反比**（像杠杆平衡），因此叫杠杆定律。合金成分点越靠近某相，该相含量越多。

杠杆定律是分析凝固过程、计算组织组成物和相组成物含量的核心工具，是第 7 章几乎所有计算题的基础。

### 例题
某二元合金总成分 C₀ = 40%B，两相平衡时 α 相含 20%B、β 相含 80%B，求两相的质量分数。

**答案**：Wα = (80−40)/(80−20) = 40/60 = 66.7%；Wβ = (40−20)/(80−20) = 20/60 = 33.3%。

## 匀晶相图
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**匀晶相图**：两组元在液态和固态都**无限互溶**，只形成单相固溶体的相图（如 Cu-Ni、Au-Ag）。相图呈透镜形，上为液相线，下为固相线，中间为 L + α 两相区。

**平衡凝固**：某成分合金从液态缓慢冷却，在液相线开始析出 α，在固相线凝固完毕。凝固过程中，**固相成分沿固相线变化，液相成分沿液相线变化**，两相相对量由杠杆定律确定。

**非平衡凝固（快速冷却）**：扩散不充分，固相内部成分来不及均匀化，先结晶的固相（含高熔点组元多）与后结晶的固相成分不同，产生**成分偏析**，即**晶内偏析（枝晶偏析）**。非平衡凝固还使凝固温度范围扩大。

消除偏析的方法：进行**均匀化退火（扩散退火）**，使原子充分扩散、成分均匀。

### 例题
匀晶合金快速冷却（非平衡凝固）会产生什么缺陷？如何消除？

**答案**：产生晶内偏析（枝晶偏析），即晶粒内部成分不均匀（先结晶部分高熔点组元多）。可通过均匀化退火（扩散退火）使原子充分扩散来消除。

## 共晶相图与共晶反应
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**共晶相图**：两组元液态无限互溶、固态有限互溶或不溶，存在**共晶反应**的相图（如 Pb-Sn、Al-Si、Fe-C）。

**共晶反应**：在一定温度（共晶温度）下，一定成分（共晶成分）的液相同时结晶出两种固相：

**L → α + β**

共晶反应在三相平衡（f = 0）的恒温下进行，相图上表现为一条**水平线（共晶线）**，共晶成分点为液相线与固相线的交点。

按合金成分不同，凝固组织分为：

- **共晶合金**（成分恰为共晶点）：全部为共晶体（α + β 交替的机械混合物）。
- **亚共晶合金**：先析出先共晶相 α，剩余液相在共晶温度转变成共晶体，组织为 α + 共晶体。
- **过共晶合金**：先析出 β + 共晶体。

用杠杆定律可计算先共晶相和共晶体的相对量。

### 例题
共晶反应的特点是什么？为什么共晶反应在恒温下进行？

**答案**：共晶反应是 L → α + β，一定成分的液相同时析出两种固相。共晶反应时三相共存（L、α、β），由相律 f = 3 − 3 = 0，自由度为 0，故在恒温下进行。

## 包晶相图与包晶反应
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：中频

### 内容
**包晶相图**中存在**包晶反应**：

**L + α → β**

即一定成分的液相与已析出的固相 α 反应，生成新的固相 β（如 Pt-Ag、Fe-C 中的 δ + L → γ）。

包晶反应也是三相平衡，在**恒温**下进行。包晶反应生成的 β 相包在 α 相周围，由于 β 相把 α 与液相隔开，包晶反应往往**不能进行完全**，常残留未反应的 α（或液相），产生**包晶偏析（包晶不完全）**。

包晶反应的特点是：新相 β 在 α 与液相的界面上形核长大，反应受扩散控制，速度慢。Fe-C 合金中，含碳约 0.09~0.17% 的钢在凝固时发生包晶反应 δ + L → γ，是连铸时产生裂纹的一个原因。

### 例题
写出包晶反应的通式，并说明其反应特点。

**答案**：包晶反应为 L + α → β。特点是：一定成分液相与固相 α 反应生成新固相 β；新相 β 在 α 与液相界面形核长大，反应受扩散控制且往往进行不完全，易产生包晶偏析。

## 其他类型的二元相图
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：中频

### 内容
除匀晶、共晶、包晶外，二元相图还有其他类型的三相反应：

1. **共析反应**：**γ → α + β**，一个固相在恒温下分解为两个固相。与共晶类似，但反应物是固相而非液相。如 Fe-C 相图中 γ → α + Fe₃C（珠光体转变，727℃）。共析产物常呈细密层片状。

2. **偏晶反应**：**L₁ → L₂ + α**，一种液相分解为另一种液相和固相（两组元液态有限互溶），如 Cu-Pb。

3. **熔晶反应**：**α → L + β**，一个固相加热时分解为液相和另一个固相。

4. **包析反应**：**α + γ → β**，两个固相反应生成一个新固相。

此外还有**有序-无序转变**、**磁性转变**等固态转变。这些反应均发生在三相平衡线上，f = 0，恒温进行。

### 例题
共析反应与共晶反应有何异同？

**答案**：相同点：都是三相平衡恒温反应，产物为两种固相（α + β），相图上均为水平线。不同点：共晶反应的反应物是液相（L → α + β），共析反应的反应物是固相（γ → α + β）。

## 铁碳（Fe-C）相图分析
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
Fe-C 相图是钢铁材料的基础，包含两类最重要的反应：

1. **共晶反应**（1148℃，4.3%C）：**L → γ（奥氏体）+ Fe₃C**，产物为**莱氏体 Ld**。
2. **共析反应**（727℃，0.77%C）：**γ → α（铁素体）+ Fe₃C**，产物为**珠光体 P**。

基本相：**铁素体 F**（C 溶于 α-Fe 的间隙固溶体，软而韧）、**奥氏体 A**（C 溶于 γ-Fe，高温相）、**渗碳体 Fe₃C**（含 6.69%C，硬而脆）。

按含碳量分类：

- **钢**（< 2.11%C）：亚共析钢（<0.77%C，组织 F + P）、共析钢（0.77%C，P）、过共析钢（0.77~2.11%C，P + Fe₃C）。
- **白口铸铁**（2.11~6.69%C）：亚共晶、共晶、过共晶白口铁（含莱氏体）。

用杠杆定律可计算珠光体中铁素体与渗碳体的相对量。

### 例题
求共析钢（0.77%C）中珠光体所含渗碳体的质量分数（铁素体室温溶碳约 0.0218%，Fe₃C 含 6.69%C）。

**答案**：W(Fe₃C) = (0.77 − 0.0218)/(6.69 − 0.0218) = 0.748/6.668 ≈ 11.2%，其余约 88.8% 为铁素体。

## 合金凝固与成分过冷
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
合金凝固时，由于溶质在固、液相中溶解度不同，凝固界面处的液相中会富集（或贫化）溶质，形成**溶质边界层**，使液相凝固温度（液相线温度）沿距界面的距离而变化。

当液相中的实际温度梯度 G 小于界面处液相线温度梯度时，在界面前沿一定范围内的液相，其**实际温度低于凝固温度**，即液相处于过冷状态，这种现象叫**成分过冷**。

**成分过冷的判据**：

**G/R < m·C₀·(1−k₀)/(D·k₀)**

其中 G 为温度梯度，R 为凝固速度，m 为液相线斜率，C₀ 为合金成分，k₀ 为平衡分配系数，D 为扩散系数。

**成分过冷决定凝固形态**：无成分过冷 → 平面晶；随成分过冷增大 → 胞状晶 → 树枝晶。合金中树枝晶普遍存在，原因即在于成分过冷。

### 例题
什么是成分过冷？它如何影响晶体生长形态？

**答案**：成分过冷是凝固界面前沿液相因溶质富集而使实际温度低于凝固温度的现象。无成分过冷时长成平面晶，成分过冷较小时长成胞状晶，成分过冷较大时长成树枝晶。

## 陶瓷相图与玻璃（无机非考点）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：中频

### 内容
**陶瓷相图**主要是氧化物二元相图（如 Al₂O₃-SiO₂、MgO-Al₂O₃、ZrO₂-CaO），用于确定陶瓷的组成与相、烧成温度、以及中间化合物（如莫来石 3Al₂O₃·2SiO₂）的生成条件。其分析方法与金属相图相同（相律、杠杆定律），但陶瓷熔点高、液相黏度大。

陶瓷相图常含有**中间化合物**（如尖晶石 MgO·Al₂O₃、莫来石），这些化合物是重要的陶瓷主晶相。

**玻璃**是**非晶态**材料，其形成与凝固特性密切相关：

- 玻璃无固定熔点，只有**玻璃化转变温度 Tg**，冷却时不发生结晶而是黏度逐渐增大形成过冷液体→玻璃。
- **玻璃形成能力**取决于临界冷却速率：成分靠近共晶点、液相黏度大、结构不对称的体系容易形成玻璃。
- 玻璃是典型的硅酸盐（SiO₂ 网络），结构为 [SiO₄] 四面体构成的无序网络，加入 Na₂O、CaO 等网络改变体可调节性能。

### 例题
为什么玻璃态结构可用"过冷液体"来理解？

**答案**：玻璃是液体冷却时黏度急剧增大、来不及结晶而形成的非晶态，内部结构保留了液体的无序特征，只是失去了流动性，因此可看作"冻结"的过冷液体，表现为无固定熔点、只有玻璃化转变温度 Tg。

## 杠杆定律计算
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**公式**（两相区中求两相相对量）：
**W_L = (C_α − C₀) / (C_α − C_L)**
**W_α = (C₀ − C_L) / (C_α − C_L)**

**符号含义**：
- C₀：合金的总（平均）成分
- C_L：与合金平衡的液相成分
- C_α：与合金平衡的固相成分
- W_L、W_α：液相、固相的质量分数（满足 W_L + W_α = 1）

**原理**：两相区中，合金点把连接两相成分点的水平线（结线）分成两段，两相质量分数与各自到合金点的"杠杆臂"成反比——距合金点越近的相，质量分数越大。杠杆定律适用于任意两相区（如匀晶、共晶、共析、包晶转变产物的相对量计算）。

### 例题
题目：Cu-Ni 匀晶合金含 Ni 35%（质量分数），某温度下与它平衡的液相含 Ni 30%、固相含 Ni 50%，求液相和固相的质量分数。

**已知**：C₀ = 35%，C_L = 30%，C_α = 50%。
**公式**：W_L = (C_α − C₀)/(C_α − C_L)；W_α = (C₀ − C_L)/(C_α − C_L)。
**代入**：W_L = (50−35)/(50−30) = 15/20 = 0.75；W_α = (35−30)/(50−30) = 5/20 = 0.25。
**结果**：液相质量分数 75%，固相质量分数 25%。
题目：Pb–Sn 共晶系中，某合金含 30%Sn，在共晶温度以上处于 α + L 两相区，此时 α 相含 19.2%Sn、液相含 61.9%Sn，求两相质量分数。
**已知**：C₀ = 30%，C_α = 19.2%，C_L = 61.9%。
**公式**：W_L = (C₀−C_α)/(C_L−C_α)；W_α = (C_L−C₀)/(C_L−C_α)。
**代入**：W_L = (30−19.2)/(61.9−19.2) = 10.8/42.7 ≈ 0.253；W_α = 1−W_L ≈ 0.747。
**结果**：液相约 25.3%，α 相约 74.7%。

题目：在 Pb–Sn 共晶合金（61.9%Sn）凝固后的共晶组织中，α 相含 19.2%Sn、β 相含 97.5%Sn，求共晶组织中 α、β 两相的相对量。
**已知**：C₀ = 61.9%，C_α = 19.2%，C_β = 97.5%。
**公式**：W_α = (C_β−C₀)/(C_β−C_α)；W_β = (C₀−C_α)/(C_β−C_α)。
**代入**：W_α = (97.5−61.9)/(97.5−19.2) = 35.6/78.3 ≈ 0.455；W_β = (61.9−19.2)/78.3 ≈ 0.545。
**结果**：α 相约 45.5%，β 相约 54.5%。

## 相图的热力学基础
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：中频

### 内容
相图是体系热力学平衡状态的图解，其形状由各组元**自由能-成分曲线**决定。

**基本原理**：在一定温度下，体系平衡的条件是吉布斯自由能最低。对给定成分的合金，比较不同相（如液相 L、固相 α）的自由能，自由能低的相稳定。

**公切线法则**：两相（α、β）平衡共存时，两相自由能曲线的**公切线**与两曲线的切点，对应两相的平衡成分；两切点之间的成分区间为两相共存区。在该区内，合金自由能取公切线（直线）上的值，低于任一单相曲线，故两相共存最稳定。

**自由能曲线与相图的关系**：温度变化使各相自由能曲线的相对位置改变，从而决定相图中各相区的范围。匀晶、共晶等转变都能由自由能曲线随温度的变化解释。

> 部分教材用 G（吉布斯自由能）或 F（亥姆霍兹自由能）表示，相图分析中常简称"自由能"。

### 例题
题目：如何用自由能-成分曲线解释"公切线法则"确定的平衡成分？

**答案**：两相平衡时，公切线与两相自由能曲线的切点即为两相的平衡成分；两切点之间为两相共存区，合金自由能取公切线值、低于任一单相，故两相共存最稳定。

## 共析转变与珠光体组织
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
共析转变是固态相变中典型的**扩散型平衡相变**：一个固相在恒温下同时分解为两个固相，即

**γ → α + Fe₃C**（共析反应，727℃，含碳 0.77%）

产物 α（铁素体）与 Fe₃C（渗碳体）两相交替排列成**层片状组织，称为珠光体（P）**。

**珠光体的形成**：过冷奥氏体在 A₁ 温度以下保温，通过碳的扩散重新分配，形成铁素体与渗碳体的层片。过冷度越大，层片间距越小、珠光体越细，强度硬度越高。

**按碳含量分类**（与铁碳相图对应）：

- **共析钢**（0.77%C）：室温组织全为珠光体。
- **亚共析钢**（<0.77%C）：先共析铁素体 + 珠光体。
- **过共析钢**（>0.77%C）：先共析渗碳体（常呈网状）+ 珠光体。

### 例题
题目：什么是共析转变？珠光体由哪两相组成？

**答案**：共析转变是一个固相（奥氏体 γ）在恒温下同时分解为两个固相的扩散型相变，即 γ → α + Fe₃C。珠光体由铁素体 α 和渗碳体 Fe₃C 两相交替排列的层片状组织构成。

## 铁素体（α-Fe 间隙固溶体）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
**铁素体（F 或 α）**是碳溶于 α-Fe（体心立方 BCC）形成的**间隙固溶体**，是室温下钢的主要基体相。

**溶碳能力极低**（BCC 间隙小）：
- 727℃（共析温度）时最大溶碳 **0.0218%**（相图 P 点）；
- 室温时仅约 **0.0008%**（相图 Q 点，可近似视为纯铁）。

**性能**：软而韧——硬度低（约 80 HB）、强度低、塑性韧性好。

**两种铁素体**（结构都是 BCC，按温度区分）：
- **α 铁素体**：912℃（G 点）以下稳定；
- **δ 铁素体（高温铁素体）**：1394℃（N 点）～1538℃（A 点）稳定，是高温区 BCC 固溶体，参与包晶反应 δ + L → γ。

铁素体在钢中的作用：作为基体相提供塑性，常与渗碳体（硬相）配合，通过两相比例与形态调节钢的强韧性。

### 例题
题目：铁素体是什么？它在 727℃ 和室温下的最大溶碳量分别是多少？为什么？

**答案**：铁素体是碳溶于 α-Fe（BCC）的间隙固溶体。727℃ 最大溶碳 0.0218%（P 点），室温仅约 0.0008%（Q 点）。原因是 α-Fe 为体心立方，间隙孔洞小而数量少，容纳碳原子能力极低。

## 奥氏体（γ-Fe 间隙固溶体）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
**奥氏体（A 或 γ）**是碳溶于 γ-Fe（面心立方 FCC）形成的**间隙固溶体**，是钢的高温相。

**溶碳能力较高**（FCC 间隙比 BCC 大）：
- 1148℃（共晶温度）时最大溶碳 **2.11%**（相图 E 点），远高于铁素体；
- 727℃（共析温度）时溶碳 **0.77%**（相图 S 点）。

**稳定温度范围**：727℃（A1 线）以上稳定；727℃ 以下分解为铁素体 + 渗碳体（共析转变）。

**性能**：硬度低、塑性极好、无磁性（顺磁），是钢进行**锻造、热轧等热加工**的理想组织（塑性好、易变形）。

**地位**：钢的一切热处理（退火、正火、淬火、回火）都要先加热到奥氏体区进行**奥氏体化**，再控制冷却得到所需组织，因此奥氏体是热处理的核心过渡相。

### 例题
题目：奥氏体的晶体结构和最大溶碳量是多少？为什么钢的热加工多在奥氏体区进行？

**答案**：奥氏体是碳溶于 γ-Fe（FCC）的间隙固溶体，1148℃ 时最大溶碳 2.11%（E 点）。FCC 结构塑性好，奥氏体硬度低、塑性极好，易变形，故热加工（锻造、热轧）多在奥氏体区进行。

## 渗碳体（Fe₃C 间隙化合物）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
**渗碳体（Fe₃C）**是铁与碳形成的**间隙化合物**，含碳固定为 **6.69%**，正交晶系复杂结构，是钢和铸铁中的**强化相（硬相）**。

**性能**：**硬而脆**——硬度极高（约 800 HB）、塑性韧性几乎为零（伸长率 ≈ 0）。单独存在时材料很脆，故需与软韧的铁素体配合使用。

**按析出来源分类**（重要考点）：
- **一次渗碳体 Fe₃CⅠ**：从液相中直接析出（过共晶白口铁）；
- **二次渗碳体 Fe₃CⅡ**：从奥氏体中析出（过共析钢、白口铁，沿晶界呈**网状**会严重损害韧性）；
- **三次渗碳体 Fe₃CⅢ**：从铁素体中析出（量极少）；
- **共晶渗碳体**（莱氏体的组成）、**共析渗碳体**（珠光体的组成）。

**亚稳相**：渗碳体是亚稳相，高温长时间保温可分解：**Fe₃C → 3Fe + C（石墨）**，这是铸铁石墨化的基础。

**作用**：一定量渗碳体提高强度、硬度、耐磨性；但网状或粗大渗碳体降低塑韧性，需通过热处理改善。

### 例题
题目：渗碳体的成分、性能有何特点？"二次渗碳体"是从哪个相中析出的？

**答案**：渗碳体含碳 6.69%，是铁碳的间隙化合物，硬而脆（约 800 HB，塑性近零）。二次渗碳体是从奥氏体（γ）中析出的渗碳体，在过共析钢中常沿晶界呈网状析出，会严重降低钢的塑韧性。

---

## 莱氏体（高温莱氏体与变态莱氏体）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**莱氏体（Ld）**是铁碳合金**共晶反应**的产物，即 1148℃、4.3%C 时：

**L → γ（奥氏体）+ Fe₃C（渗碳体）**，二者组成的机械混合物叫莱氏体。

按温度分为两种（必考）：

1. **高温莱氏体（Ld）**：1148℃～727℃ 之间，组织为 **奥氏体 + 渗碳体**。
2. **低温莱氏体（变态莱氏体，Ld′）**：727℃ 以下，莱氏体中的奥氏体发生共析转变变成珠光体，组织变为 **珠光体 + 渗碳体**，称为变态（低温）莱氏体。

**特征与地位**：
- 含大量渗碳体，**硬而脆**，是**白口铸铁**的基本组织；
- 使白口铸铁耐磨、但脆性大、难以切削加工；
- 因为脆，白口铸铁一般不能直接承受冲击，工业上多作耐磨件或炼钢、可锻铸铁的原料。

**注意区分**：莱氏体是"组织"概念（奥氏体/珠光体 + 渗碳体的混合物），在"相"的角度它仍由 γ（或 α）与 Fe₃C 两相组成。

### 例题
题目：高温莱氏体与变态莱氏体在组织上有什么区别？莱氏体是哪个反应的产物？

**答案**：莱氏体是共晶反应 L → γ + Fe₃C（1148℃，4.3%C）的产物。高温莱氏体（727℃ 以上）组织为奥氏体 + 渗碳体；变态莱氏体（727℃ 以下）中奥氏体已共析转变为珠光体，组织为珠光体 + 渗碳体。

## 铁碳相图的特征线：A1、A3、Acm
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
铁碳相图（Fe-Fe₃C 亚稳系）中有三条对热处理至关重要的**特征温度线**：

1. **A1 线（PSK 线，727℃）——共析线**：奥氏体 ⇌ 珠光体（α + Fe₃C）的转变温度。**任何成分的钢**加热或冷却都要经过 A1，是确定热处理温度的基础。

2. **A3 线（GS 线）——铁素体析出线**：奥氏体与铁素体的转变线，即亚共析钢中**铁素体从奥氏体中开始析出（冷却）或全部溶入奥氏体（加热）**的温度。A3 温度随含碳量升高而降低（0%C 时 912℃ → 0.77%C 时 727℃）。

3. **Acm 线（ES 线）——碳在奥氏体中的溶解度线**：过共析钢中**二次渗碳体从奥氏体中开始析出（冷却）或全部溶入（加热）**的温度。Acm 温度随含碳量升高而升高（0.77%C 时 727℃ → 2.11%C 时 1148℃）。

**实用加热温度（必记）**：
- 亚共析钢淬火加热：**Ac3 + 30～50℃**（完全奥氏体化，避免铁素体残留）；
- 共析钢、过共析钢淬火加热：**Ac1 + 30～50℃**（不完全奥氏体化，保留部分渗碳体提高耐磨性）。

**符号说明**：加热时实际转变温度略高于平衡温度用 **Ac**（c = chauffage 加热），冷却时略低于平衡温度用 **Ar**（r = refroidissement 冷却），下标 1/3/cm 对应 A1/A3/Acm。另有 **A2 线（770℃）**为磁性转变（居里点），不是相变。

### 例题
题目：写出 A1、A3、Acm 三条线各自的含义，并说明亚共析钢与过共析钢淬火加热温度如何确定。

**答案**：A1（727℃，PSK）是共析线，奥氏体⇌珠光体转变温度；A3（GS）是铁素体从奥氏体析出/溶入线；Acm（ES）是碳在奥氏体中的溶解度线（二次渗碳体析出/溶入线）。亚共析钢淬火加热 Ac3+30～50℃（完全奥氏体化），过共析钢与共析钢加热 Ac1+30～50℃（保留渗碳体）。

## 钢与铸铁的区分（含工业纯铁）
- 章节：第7章 二元系相图及其合金的凝固
- 难度：基础
- 考点频率：高频

### 内容
按**含碳量**对铁碳合金分类，分界点是相图中的两个特殊点：

**总的分界——2.11%C（E 点，碳在奥氏体中最大溶解度）**：
- 含碳 **< 2.11%** 称为**钢**；
- 含碳 **2.11%～6.69%** 称为**铸铁**（白口铸铁，含莱氏体）。

**细分（必考）**：

| 类别 | 含碳量 | 室温组织 |
|---|---|---|
| 工业纯铁 | < 0.0218%（P 点） | 铁素体（+ 极少量三次渗碳体） |
| 亚共析钢 | 0.0218%～0.77% | 铁素体 F + 珠光体 P |
| 共析钢 | 0.77%（S 点） | 珠光体 P |
| 过共析钢 | 0.77%～2.11% | 珠光体 P + 网状二次渗碳体 Fe₃CⅡ |
| 亚共晶白口铁 | 2.11%～4.3% | 珠光体 + 二次渗碳体 + 变态莱氏体 Ld′ |
| 共晶白口铁 | 4.3%（C 点） | 变态莱氏体 Ld′ |
| 过共晶白口铁 | 4.3%～6.69% | 一次渗碳体 Fe₃CⅠ + 变态莱氏体 Ld′ |

**记忆要点**：
- 钢与铸铁的本质区别在于**有没有莱氏体**（含碳超过 2.11% 就出现莱氏体组织）。
- 亚共析钢与过共析钢以**共析成分 0.77%** 为界；
- 亚共晶、共晶、过共晶白口铁以**共晶成分 4.3%** 为界。

**注意**：以上按 Fe-Fe₃C（亚稳系）讨论；灰口铸铁（含石墨）对应 Fe-C 稳定系，是另一套分类，考试默认铁碳合金相图为 Fe-Fe₃C 系。

### 例题
题目：钢与铸铁的分界含碳量是多少？为什么以这个含量为界？

**答案**：分界含碳量为 2.11%（E 点，碳在奥氏体中的最大溶解度）。含碳 < 2.11% 为钢（无莱氏体），2.11%～6.69% 为白口铸铁（含莱氏体）。因为超过 2.11% 时，共晶反应开始出现、形成莱氏体组织，材料由可锻造的钢变为脆硬的白口铸铁。

## 相组成物与组织组成物的区别
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
这是铁碳相图计算题**最容易失分**的概念区分。

**相组成物（相）**：合金在平衡态下由哪几"**相**"构成。相是**物理、化学性质均匀**的部分，有明确的成分和结构。铁碳合金中的相只有：**铁素体 α、奥氏体 γ、渗碳体 Fe₃C、液相 L**（δ 铁素体可并入铁素体）。

**组织组成物（组织）**：显微组织由哪几"**种组织**"构成。组织是相的**集合体/形貌**，如珠光体 P 是 α + Fe₃C 两相组成的层片状混合物，但它算"**一种组织**"。

**核心区别（必记）**：
- 珠光体在"**相**"上是 α 和 Fe₃C **两相**，但在"**组织**"上是**一种**（珠光体）；
- 莱氏体在"相"上是 γ（或 α）+ Fe₃C 两相，在"组织"上是一种（莱氏体）。

**计算时的差别**：
- 求**相**相对量：用两相区两端**相**的成分（如 α 与 Fe₃C 的含碳量 0.0218% 和 6.69%）做杠杆；
- 求**组织**相对量：用**组织**对应的成分做杠杆（如珠光体整体按 0.77% 算，莱氏体整体按 4.3% 算）。

**例**：0.45%C 亚共析钢室温下——
- 相组成物：铁素体 α + 渗碳体 Fe₃C（两相）；
- 组织组成物：先共析铁素体 F + 珠光体 P（两种组织）。

同一个合金，"相"和"组织"的答案不同，答题时先看清题目问的是哪个。

### 例题
题目：0.45%C 亚共析钢室温下，它的"相组成物"和"组织组成物"分别是什么？

**答案**：相组成物是铁素体 α 和渗碳体 Fe₃C 两相；组织组成物是先共析铁素体 F 和珠光体 P 两种组织。珠光体是 α + Fe₃C 两相的层片混合物，算一种组织而非一个相。

## 【计算】铁碳相图—杠杆定律求相组成物
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**题型**：已知合金含碳量，求某温度（两相区）下**相组成物**（各"相"的质量分数）。这是最基础的杠杆定律应用，用**两相区两端"相"的成分**做杠杆。

**铁碳相图关键"相"成分**：
- 铁素体 α：727℃ 溶碳 0.0218%（P 点）；
- 渗碳体 Fe₃C：含碳 6.69%；
- 奥氏体 γ：1148℃ 溶碳 2.11%（E 点）。

**通用公式**（合金成分 C₀ 处于两相区，两相成分为 C₁、C₂，C₁ < C₀ < C₂）：
W(右相，成分 C₂) = (C₀ − C₁)/(C₂ − C₁)；W(左相) = 1 − W(右相)。

### 例题
题目1：0.45%C 亚共析钢在 727℃（共析温度）稍下（α + Fe₃C 两相区），求相组成物（铁素体与渗碳体）的质量分数。

**已知**：C₀ = 0.45%，α 含 0.0218%C，Fe₃C 含 6.69%C。
**公式**：W(Fe₃C) = (C₀ − 0.0218)/(6.69 − 0.0218)；W(α) = 1 − W(Fe₃C)。
**分步解答**：
① 0.45%C 在 727℃ 稍下处于 α + Fe₃C 两相区；
② 查相图得两相成分：α = 0.0218%，Fe₃C = 6.69%；
③ 套杠杆定律：W(Fe₃C) = (0.45 − 0.0218)/(6.69 − 0.0218) = 0.4282/6.6682；
④ 计算得 W(Fe₃C) = 6.42%，W(α) = 1 − 6.42% = 93.58%。
**标准答案**：铁素体 α 约 93.58%，渗碳体 Fe₃C 约 6.42%。
**易错点**：求"相组成物"时两相成分必须取**相**的成分（0.0218% 和 6.69%），不能把珠光体的 0.77% 当成一端。

题目2：4.30%C 共晶白口铁在 1148℃（共晶温度）稍下（γ + Fe₃C 两相区），求相组成物（奥氏体与渗碳体）的质量分数。

**已知**：C₀ = 4.30%，γ 含 2.11%C，Fe₃C 含 6.69%C。
**公式**：W(Fe₃C) = (4.30 − 2.11)/(6.69 − 2.11)；W(γ) = 1 − W(Fe₃C)。
**分步解答**：① 1148℃ 稍下处于 γ + Fe₃C 两相区；② 两相成分 γ = 2.11%、Fe₃C = 6.69%；③ W(Fe₃C) = 2.19/4.58；④ 得 W(Fe₃C) = 47.82%，W(γ) = 52.18%。
**标准答案**：奥氏体 γ 约 52.18%，渗碳体 Fe₃C 约 47.82%。
**易错点**：共晶白口铁在共晶温度稍下两相是 γ 和 Fe₃C（不是 α），γ 端成分取 2.11%（E 点）。

题目3：3.0%C 亚共晶白口铁在 1148℃ 稍下（γ + Fe₃C 两相区），求相组成物（奥氏体与渗碳体）的质量分数。

**已知**：C₀ = 3.0%，γ 含 2.11%C，Fe₃C 含 6.69%C。
**公式**：W(Fe₃C) = (3.0 − 2.11)/(6.69 − 2.11)；W(γ) = 1 − W(Fe₃C)。
**分步解答**：① 3.0%C 亚共晶白口铁在 1148℃ 稍下为 γ + Fe₃C 两相区；② W(Fe₃C) = 0.89/4.58；③ 得 W(Fe₃C) = 19.43%，W(γ) = 80.57%。
**标准答案**：奥氏体 γ 约 80.57%，渗碳体 Fe₃C 约 19.43%。
**易错点**：这里求的是"相"，γ 里还没发生共析转变，不能把 γ 当珠光体处理。

## 【计算】铁碳相图—杠杆定律求组织组成物
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
**题型**：求**组织组成物**（各"组织"的质量分数），如先共析铁素体/珠光体、二次渗碳体/珠光体、先共晶奥氏体/莱氏体。关键是用**"组织"对应的成分**做杠杆，而不是"相"的成分。

**常用"组织"代表成分**：
- 珠光体 P：整体含碳 **0.77%**（共析成分）；
- 莱氏体 Ld：整体含碳 **4.3%**（共晶成分）；
- 先共析铁素体：0.0218%；二次渗碳体：6.69%。

### 例题
题目1：0.45%C 亚共析钢室温（727℃ 稍下），求组织组成物（先共析铁素体与珠光体）的质量分数。

**已知**：C₀ = 0.45%，先共析铁素体含 0.0218%C，珠光体含 0.77%C。
**公式**：W(P) = (0.45 − 0.0218)/(0.77 − 0.0218)；W(先共析 F) = 1 − W(P)。
**分步解答**：① 亚共析钢组织 = 先共析铁素体 + 珠光体；② 用"组织"成分做杠杆：一端 0.0218%（铁素体），一端 0.77%（珠光体）；③ W(P) = 0.4282/0.7482；④ 得 W(P) = 57.23%，W(先共析 F) = 42.77%。
**标准答案**：珠光体 P 约 57.23%，先共析铁素体 F 约 42.77%。
**易错点**：求"组织"时珠光体一端取 **0.77%**（不是渗碳体的 6.69%）；只有求"相"时渗碳体端才取 6.69%。

题目2：1.2%C 过共析钢室温（727℃ 稍下），求组织组成物（珠光体与二次渗碳体）的质量分数。

**已知**：C₀ = 1.2%，珠光体含 0.77%C，二次渗碳体含 6.69%C。
**公式**：W(P) = (6.69 − 1.2)/(6.69 − 0.77)；W(Fe₃CⅡ) = (1.2 − 0.77)/(6.69 − 0.77)。
**分步解答**：① 过共析钢组织 = 珠光体 + 网状二次渗碳体；② 用组织成分做杠杆，C₀ 在 0.77% 与 6.69% 之间；③ W(P) = 5.49/5.92，W(Fe₃CⅡ) = 0.43/5.92；④ 得 W(P) = 92.74%，W(Fe₃CⅡ) = 7.26%。
**标准答案**：珠光体 P 约 92.74%，二次渗碳体 Fe₃CⅡ 约 7.26%。
**易错点**：二次渗碳体是"组织"（沿晶界网状），其成分按 6.69% 算；但它是从奥氏体中析出的，别与珠光体内部的渗碳体混为一谈。

题目3：3.0%C 亚共晶白口铁在 1148℃（共晶温度稍上），求组织组成物（先共晶奥氏体与莱氏体）的质量分数。

**已知**：C₀ = 3.0%，奥氏体含 2.11%C，莱氏体含 4.3%C。
**公式**：W(Ld) = (3.0 − 2.11)/(4.3 − 2.11)；W(先共晶 γ) = 1 − W(Ld)。
**分步解答**：① 亚共晶白口铁 = 先共晶奥氏体 + 莱氏体；② 用组织成分做杠杆：一端 2.11%（γ），一端 4.3%（Ld）；③ W(Ld) = 0.89/2.19；④ 得 W(Ld) = 40.64%，W(先共晶 γ) = 59.36%。
**标准答案**：莱氏体 Ld 约 40.64%，先共晶奥氏体 γ 约 59.36%。冷却到室温后，先共晶奥氏体转变为珠光体，莱氏体变为变态莱氏体 Ld′，两者的相对量不变。
**易错点**：莱氏体按 4.3%（共晶成分）作"组织"端；若题目问的是室温，还要说明奥氏体→珠光体、Ld→Ld′ 的转变。

## 【计算】铁碳相图—判断合金的相与组织
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
**题型**：给定成分合金在几个温度下，判断（1）由哪几**相**组成，（2）是哪种**组织**。这类题考的是对相图各相区位置的熟悉程度，计算成分较少，重在"看图定位"。

**步骤口诀**：
① 在相图上定位该成分的竖线；② 由给定温度作水平线（结线）；③ 看交点落在哪个相区；④ 报出相与组织。

**亚共析钢（0.0218%～0.77%）**降温过程相/组织变化：
液相 L → L+δ → δ+γ → γ（奥氏体）→ γ+α（A3 以下析出先共析铁素体）→ α+Fe₃C（A1 以下，组织为 F + P）。

**过共析钢（0.77%～2.11%）**：γ → γ+Fe₃CⅡ（Acm 以下析出二次渗碳体）→ α+Fe₃C（组织为 P + 网状 Fe₃CⅡ）。

### 例题
题目1：0.45%C 亚共析钢，判断在（a）850℃、（b）750℃、（c）室温下的相组成与组织组成物。

**已知**：0.45%C 的 A3 温度约 790℃（GS 线上）。
**分步解答**：
（a）850℃：高于 A3，处于 γ 单相区 → **相**：奥氏体 γ；**组织**：奥氏体 A。
（b）750℃：A3（约 790℃）与 A1（727℃）之间，处于 γ+α 两相区 → **相**：奥氏体 γ + 铁素体 α；**组织**：奥氏体 + 铁素体。
（c）室温（< 727℃）：处于 α+Fe₃C 两相区 → **相**：铁素体 α + 渗碳体 Fe₃C；**组织**：先共析铁素体 F + 珠光体 P（亚共析钢）。
**标准答案**：850℃ 相为 γ（组织 A）；750℃ 相为 γ+α；室温相为 α+Fe₃C（组织 F+P）。
**易错点**：750℃ 是在 A3 与 A1 之间，别误判成"全奥氏体"；室温要说清"相"（α+Fe₃C）和"组织"（F+P）两套答案。

题目2：1.2%C 过共析钢，判断在（a）1100℃、（b）900℃、（c）室温下的相组成与组织组成物。

**已知**：1.2%C 的 Acm 温度约 1010℃（ES 线上）。
**分步解答**：
（a）1100℃：高于 Acm，处于 γ 单相区 → **相**：奥氏体 γ；**组织**：奥氏体 A。
（b）900℃：Acm（约 1010℃）与 A1（727℃）之间，处于 γ+Fe₃C 两相区 → **相**：奥氏体 γ + 渗碳体 Fe₃C；**组织**：奥氏体 + 二次渗碳体 Fe₃CⅡ。
（c）室温（< 727℃）：处于 α+Fe₃C 两相区 → **相**：铁素体 α + 渗碳体 Fe₃C；**组织**：珠光体 P + 网状二次渗碳体 Fe₃CⅡ（过共析钢）。
**标准答案**：1100℃ 相为 γ（组织 A）；900℃ 相为 γ+Fe₃C（组织 γ+Fe₃CⅡ）；室温相为 α+Fe₃C（组织 P+网状 Fe₃CⅡ）。
**易错点**：过共析钢在 Acm 与 A1 之间析出的是**二次渗碳体**（不是铁素体）；室温组织要强调二次渗碳体呈**网状**分布。

## 【计算】铁碳相图—室温组织相对量
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
**题型**：求合金在**室温**下的组织（或相）相对量，常要综合两次杠杆定律，或区分"相组成物"与"组织组成物"两问。

**解题要点**：
- 相组成物按室温两相区（α + Fe₃C）两端成分算，室温铁素体溶碳约 0.0008%（可近似 0）；
- 组织组成物按各组织的代表成分（珠光体 0.77%、莱氏体 4.3%）算；
- 白口铁室温组织中的莱氏体要写成**变态莱氏体 Ld′**。

### 例题
题目1：0.2%C 亚共析钢室温下，求（1）相组成物中铁素体与渗碳体的质量分数；（2）组织组成物中铁素体与珠光体的质量分数。

**已知**：室温铁素体溶碳约 0.0008%，渗碳体含 6.69%，珠光体含 0.77%，727℃ 铁素体溶碳 0.0218%。
**分步解答**：
（1）相组成物（α+Fe₃C 两相区，室温端 α = 0.0008%）：
W(Fe₃C) = (0.2 − 0.0008)/(6.69 − 0.0008) = 0.1992/6.6892 = 2.98%；W(α) = 97.02%。
（2）组织组成物（先共析铁素体 F + 珠光体 P，铁素体端用 0.0218%）：
W(P) = (0.2 − 0.0218)/(0.77 − 0.0218) = 0.1782/0.7482 = 23.82%；W(F) = 76.18%。
**标准答案**：相组成物——铁素体约 97.02%、渗碳体约 2.98%；组织组成物——铁素体约 76.18%、珠光体约 23.82%。
**易错点**：求"相"和求"组织"两端成分不同：相用 0.0008%（室温铁素体），组织用 0.0218%（先共析铁素体）；两者结果不同，务必分清。

题目2：5.0%C 过共晶白口铁室温下，求组织组成物（一次渗碳体与变态莱氏体）的质量分数。

**已知**：C₀ = 5.0%，莱氏体含 4.3%，渗碳体含 6.69%。
**公式**：W(Ld) = (6.69 − 5.0)/(6.69 − 4.3)；W(Fe₃CⅠ) = (5.0 − 4.3)/(6.69 − 4.3)。
**分步解答**：① 过共晶白口铁组织 = 一次渗碳体 Fe₃CⅠ + 莱氏体；② 用组织成分做杠杆，C₀ 在 4.3% 与 6.69% 之间；③ W(Ld) = 1.69/2.39，W(Fe₃CⅠ) = 0.7/2.39；④ 得 W(Ld) = 70.71%，W(Fe₃CⅠ) = 29.29%。
**标准答案**：变态莱氏体 Ld′ 约 70.71%，一次渗碳体 Fe₃CⅠ 约 29.29%。
**易错点**：一次渗碳体（Fe₃CⅠ）是从**液相**直接析出的粗大条状渗碳体，与二次渗碳体（从奥氏体析出）来源不同；室温下莱氏体已变为变态莱氏体，写答案要用 Ld′。

## 如何画铁碳（Fe-Fe₃C）相图
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
画铁碳相图是主观题/作图题常见考点。按下面 6 步画，保证不丢关键分。

**第 1 步：画坐标轴**。纵轴为温度（0～1600℃），横轴为含碳量（0～6.69%，最右端为 Fe₃C 成分）。

**第 2 步：标关键点**（先标点，再连线）：
- A(1538℃, 0%)：纯铁熔点；N(1394℃, 0%)：δ↔γ；G(912℃, 0%)：γ↔α；
- H(1495℃, 0.09%)、J(1495℃, 0.17%)、B(1495℃, 0.53%)：包晶线上三点；
- E(1148℃, 2.11%)、C(1148℃, 4.3%)、F(1148℃, 6.69%)：共晶线上三点；
- S(727℃, 0.77%)、P(727℃, 0.0218%)、K(727℃, 6.69%)：共析线上三点；
- D(约 1227℃, 6.69%)：Fe₃C 熔点。

**第 3 步：画液相线与固相线**。液相线 ABCD（A→B→C→D 向下凹的曲线）；固相线 AHJECF（A→H→J→E，再沿共晶线 ECF）。

**第 4 步：画三条水平线（三相平衡）**：
- 包晶线 HJB（1495℃）；共晶线 ECF（1148℃）；共析线 PSK（727℃）。

**第 5 步：画固态转变线**：
- GS 线（A3，G→S）、ES 线（Acm，E→S）、GP 线（G→P）、PQ 溶解度线（P→Q，很陡、几乎贴左轴）。

**第 6 步：标相区与反应**。填各相区字母：L、L+δ、δ、δ+γ、L+γ、γ、α、α+γ、α+Fe₃C、γ+Fe₃C、L+Fe₃C。最后标注三个反应式：
- 包晶：L + δ → γ（1495℃，J 点）；
- 共晶：L → γ + Fe₃C（1148℃，C 点，生成莱氏体）；
- 共析：γ → α + Fe₃C（727℃，S 点，生成珠光体）。

**记忆提示**：共晶点 C、共析点 S 两个点最关键；三个水平温度 1495/1148/727，三个特殊成分 0.77/2.11/4.3 要脱口而出。

### 例题
题目：画出 Fe-Fe₃C 相图（示意），标出共晶点、共析点及三条水平线的温度，并写出三个三相反应式。

**答案**：关键点 C(1148℃, 4.3%)、S(727℃, 0.77%)；三条水平线：包晶线 1495℃、共晶线 1148℃、共析线 727℃。反应：包晶 L+δ→γ；共晶 L→γ+Fe₃C（莱氏体）；共析 γ→α+Fe₃C（珠光体）。

## 如何画冷却曲线并标注组织转变
- 章节：第7章 二元系相图及其合金的凝固
- 难度：较难
- 考点频率：高频

### 内容
作图题常要求"画出某成分合金的冷却曲线，并标注各阶段的组织"。以 **0.45%C 亚共析钢**为例，从液相缓冷到室温：

**第 1 步：画坐标**。纵轴温度、横轴时间（向右降温），先画一条自上而下的冷却曲线。

**第 2 步：在曲线上标转折点**（对应相图上的相界线），按温度从高到低：
1. **液相线以上**：全液相 L（冷却曲线先是一段平滑下降）；
2. **液相线～固相线**：L → δ（或 γ）析出，放热使曲线出现**拐点（斜率变小）**；
3. **全奥氏体区**：单相 γ，曲线平滑下降；
4. **A3 线（约 790℃）**：γ 中析出先共析铁素体 α，出现拐点；
5. **A1 线（727℃）**：剩余 γ 发生共析转变 γ → α + Fe₃C（珠光体），这是**恒温转变**，曲线上出现**水平平台**；
6. **727℃ 以下至室温**：组织不变，为 F + P，曲线继续下降。

**第 3 步：标注各阶段组织**（从上到下）：
L → L+δ → δ+γ → γ → γ+α（先共析 F 析出）→ α+Fe₃C（F + P）。

**其它成分对照（必会）**：
- **共析钢 0.77%C**：无先共析相，只在 727℃ 出现一个平台（γ → P），平台最长；
- **过共析钢 1.2%C**：Acm 线析出二次渗碳体 Fe₃CⅡ，727℃ 平台（γ → P），室温组织 P + 网状 Fe₃CⅡ；
- **亚共晶白口铁 3.0%C**：1148℃ 共晶平台（L → γ + Fe₃C，生成莱氏体），727℃ 共析平台（γ → P），室温 P + Fe₃CⅡ + Ld′；
- **共晶白口铁 4.3%C**：只在 1148℃ 一个共晶平台，727℃ 再一个共析平台，室温 Ld′。

**得分点**：① 平台必须画在恒温转变处（A1、共晶）；② 平台长度反映该转变量的多少；③ 每段都要写清组织。

### 例题
题目：画出 0.45%C 亚共析钢的冷却曲线（平衡冷却），标注各阶段相或组织，指出出现"平台"的温度及原因。

**答案**：冷却曲线上在 727℃（A1 线）出现水平平台，原因是剩余奥氏体发生共析转变 γ → α + Fe₃C（珠光体），此转变在三相平衡（f=0）恒温下进行。各阶段组织从上到下：L → L+δ → δ+γ → γ → γ+α → α+Fe₃C（室温为 F + P）。

## 铁碳相图组织转变的标注规范
- 章节：第7章 二元系相图及其合金的凝固
- 难度：中等
- 考点频率：高频

### 内容
作图题中"标注组织/相变"有固定规范，标错会扣分。记住以下标注规则：

**1. 三个三相反应式（必须写全温度、成分）**：
- 包晶反应：**L + δ → γ**（1495℃，0.17%C，J 点）；
- 共晶反应：**L → γ + Fe₃C**（1148℃，4.3%C，C 点），产物**莱氏体 Ld**；
- 共析反应：**γ → α + Fe₃C**（727℃，0.77%C，S 点），产物**珠光体 P**。

**2. 相区字母标注**（用希腊字母表示相，大写组织符号表示组织）：
- 相：L（液相）、δ、γ（奥氏体）、α（铁素体）、Fe₃C（渗碳体）；
- 组织：A（奥氏体组织）、F（铁素体组织）、P（珠光体）、Ld（莱氏体）、Ld′（变态莱氏体）。

**3. 相 vs 组织的书写区别**：
- 写"相"用 α、γ、Fe₃C；
- 写"组织"用 F、P、Ld，且珠光体/莱氏体不是相、不能写进"相组成"。

**4. 渗碳体的标号**（按来源，下标Ⅰ/Ⅱ/Ⅲ）：
- Fe₃CⅠ 一次渗碳体（液相析出）、Fe₃CⅡ 二次渗碳体（奥氏体析出）、Fe₃CⅢ 三次渗碳体（铁素体析出）。

**5. 降温转变过程的标准写法**（例 0.45%C 钢）：
L → L+δ → δ+γ → γ → γ+α → α+Fe₃C（室温组织 F + P）。

**6. 常见丢分点**：
- 漏写反应温度或成分；
- 把珠光体 P 当成"相"写进相组成物；
- 室温白口铁仍写 Ld（应写变态莱氏体 Ld′）；
- 过共析钢漏标"网状"二次渗碳体；
- 混淆共晶（1148℃/4.3%）与共析（727℃/0.77%）的对应关系。

### 例题
题目：写出铁碳相图三个三相平衡反应式（含温度、成分、产物），并说明"相"与"组织"标注符号的区别。

**答案**：包晶 L+δ→γ（1495℃，0.17%C）；共晶 L→γ+Fe₃C（1148℃，4.3%C，产物莱氏体）；共析 γ→α+Fe₃C（727℃，0.77%C，产物珠光体）。相用 α、γ、Fe₃C 表示；组织用 F、P、Ld 表示，珠光体、莱氏体是组织而非相。
