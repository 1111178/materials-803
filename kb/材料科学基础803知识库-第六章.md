## 单元系相图
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：基础
- 考点频率：中频

### 内容
**单元系**是只含一种组元的系统（C = 1）。由相律：

**f = C − P + 2 = 3 − P**（恒压时为 f = 2 − P）

其中 f 为自由度，P 为相数。由此可知：单相区 f = 2（温度和压力可独立变化），两相平衡 f = 1（温度压力只有一个独立变量），**三相平衡 f = 0**（温度压力都固定，即三相点）。

典型单元系相图：

- **水的相图**：有固、液、气三个单相区，三条两相平衡线，一个三相点（0.01℃，611 Pa）。
- **纯铁相图**：以温度-压力（或温度-压强）表示，反映 α-Fe、γ-Fe、δ-Fe 的同素异构转变。

两相平衡线的斜率由**克劳修斯-克拉珀龙方程**决定：

**dP/dT = ΔH / (T·ΔV)**

其中 ΔH 为相变潜热，ΔV 为相变体积变化。熔化时固→液 ΔV 很小，故熔化线很陡。

### 例题
单元系中三相平衡时自由度为多少？说明理由。

**答案**：f = 0。由相律 f = C − P + 2 = 1 − 3 + 2 = 0，三相平衡时温度、压力都不能自由改变，是固定值（三相点）。

## 凝固的热力学条件（过冷度）
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：基础
- 考点频率：高频

### 内容
纯晶体能否凝固（结晶），取决于固、液两相的**自由能**高低。在熔点 Tm 时，固相和液相自由能相等（ΔG = 0），两相平衡；只有当温度**低于 Tm** 时，固相自由能才低于液相，凝固才有热力学驱动力。

**过冷度** ΔT = Tm − T，是凝固的驱动力。过冷度越大，液、固两相自由能差（单位体积）的绝对值 |ΔGv| 越大：

**|ΔGv| = Lm·ΔT / Tm**

其中 Lm 为熔化潜热。可见 |ΔGv| 与过冷度 ΔT 成正比。

因此，实际结晶必须在**过冷**条件下才能进行，这就是"结晶需要过冷"的热力学原因。纯金属的凝固温度低于熔点，冷却曲线上会出现**过冷谷**（温度先降到 Tm 以下再回升），温差即过冷度。

### 例题
为什么纯金属结晶时必须过冷？

**答案**：在熔点 Tm 时固液两相自由能相等，无凝固驱动力；只有过冷到 Tm 以下，固相自由能才低于液相，ΔGv = Lm·ΔT/Tm > 0 提供凝固驱动力，故结晶必须过冷。

## 均匀形核
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：中等
- 考点频率：高频

### 内容
**均匀形核**是指在不含任何外来界面的均匀液相中，依靠液相自身的能量起伏、结构起伏自发形成晶核。

形核时体系自由能变化由两部分组成：

**ΔG = V·ΔGv + S·σ**

其中 ΔGv 为液相→固相单位体积自由能变化（负值，是形核驱动力），σ 为固-液界面能（正值，是形核阻力）。当晶核半径 r 较小时，表面能占主导，ΔG 随 r 增大而增大；r 超过**临界晶核半径 r\*** 后，体积自由能占主导，ΔG 开始下降，晶核才能稳定长大。

**临界晶核半径**：

**r\* = −2σ / ΔGv = 2σ·Tm / (Lm·ΔT)**

**临界形核功**：

**ΔG\* = 16πσ³ / (3·ΔGv²)**

结论：过冷度 ΔT 越大，|ΔGv| 越大，r* 和 ΔG* 越小，形核越容易。因此**过冷度越大，形核率越高，晶粒越细小**。

### 例题
均匀形核的临界晶核半径 r* 与过冷度 ΔT 的关系是什么？

**答案**：r* = 2σ·Tm/(Lm·ΔT)，r* 与过冷度 ΔT 成反比。过冷度越大，临界晶核半径越小，越容易形核。

## 非均匀形核
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：中等
- 考点频率：高频

### 内容
**非均匀形核**是晶核依附于液相中的外来表面（如铸型壁、夹杂物、杂质粒子、形核剂）形成的过程。由于依附在已有界面上形核，能显著降低界面能，故形核功大大减小。

非均匀形核功与均匀形核功的关系：

**ΔG\*非均匀 = ΔG\*均匀 · f(θ)**

其中 f(θ) = (2 − 3cosθ + cos³θ)/4，θ 为晶核与基底之间的**润湿角**。θ 越小（晶核与基底润湿越好），f(θ) 越小，形核功越小，越容易形核。当 θ = 0° 时 f(θ) = 0（不需形核功），θ = 180° 时 f(θ) = 1（退化为均匀形核）。

非均匀形核是**实际凝固的主要形核方式**。工业上通过加入**变质剂、形核剂**（如铝中加 Ti、B）降低润湿角、提供形核基底，使晶粒细化。

### 例题
为什么实际金属凝固的形核率远高于均匀形核理论值？

**答案**：实际金属凝固以非均匀形核为主，晶核依附外来表面（模壁、夹杂、形核剂）形成，形核功仅为均匀形核的 f(θ) 倍（f(θ) < 1），所需过冷度小，故形核率远高于均匀形核。

## 晶体长大
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：中等
- 考点频率：中频

### 内容
晶核形成后，原子不断向晶核表面堆砌，晶核长大。长大方式取决于固-液界面微观结构：

- **粗糙界面（非小平面）**：原子可连续不断地在界面各处堆砌，为**连续长大（垂直长大）**，速度快，金属多为这种界面。
- **光滑界面（小平面）**：界面原子面平整，需通过**二维形核**或**螺位错台阶**长大，速度慢，非金属、某些化合物属这种界面。

**晶体宏观形态由温度梯度决定**：

- **正温度梯度**（液体温度随距界面距离增加而升高）：界面只能平面前沿推进，长成**平面晶**（或胞状晶）。
- **负温度梯度**（液体过冷度随距离增加而增大）：界面突出部分伸入过冷度更大的区域而优先生长，长成**树枝晶（枝晶）**。

铸锭通常外部为细晶区（表面急冷形核多）、内部为柱状晶或等轴晶，即与温度梯度分布有关。

### 例题
为什么负温度梯度下晶体长成树枝状？

**答案**：负温度梯度下，距界面越远的液体过冷度越大，界面上任何突出部分伸入过冷更大的区域，生长更快，形成枝晶主干并长出枝臂，故长成树枝晶。

## 形核率与结晶动力学
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：中等
- 考点频率：中频

### 内容
结晶过程是形核与长大的综合结果，其快慢由**形核率 N** 和**长大速率 G** 共同决定。

**形核率 N**：单位时间、单位体积液体中形成的晶核数，由形核因子和扩散因子两项乘积决定：

**N = K·exp(−ΔG*/kT)·exp(−Q/kT)**

其中 ΔG* 为临界形核功（随过冷度增大而减小），Q 为原子扩散激活能（温度降低使扩散变慢）。

因此形核率随过冷度 ΔT 的关系呈**先增后减、有极大值**：过冷度较小时 ΔG* 大、形核难；过冷度很大时温度低、原子扩散慢，形核率反而下降。

**结晶动力学**：结晶速率取决于 N 和 G 的综合作用。金属结晶过冷度一般不大（非均匀形核），形核率随过冷度增大而增大，故**过冷度越大，晶粒越细小**（这是细化晶粒、强化材料的重要依据）。

### 例题
题目：为什么形核率随过冷度增大不是一直增大，而是先增后减？

**答案**：形核率 N 正比于形核因子 exp(−ΔG*/kT) 与扩散因子 exp(−Q/kT) 的乘积。过冷度增大时 ΔG* 减小、形核变易，使 N 增大；但温度降低使原子扩散变慢（Q 项减小），使 N 减小。两者竞争，故 N 随过冷度先增后减、存在极大值。

## 铸锭组织与晶粒细化
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：基础
- 考点频率：高频

### 内容
铸锭（铸件）凝固后的宏观组织通常由**三个晶区**组成（由表及里）：

1. **表面细晶区（激冷区）**：表层液体激冷，过冷度大、形核率高，形成细小等轴晶。
2. **柱状晶区**：细晶区形成后，热量沿垂直于模壁方向散失，晶粒沿散热反方向择优生长，形成平行排列的柱状晶。
3. **中心等轴晶区**：心部散热慢、过冷度小，且杂质富集促进形核，形成较粗大的等轴晶。

**晶粒细化的措施**（细化晶粒可同时提高强度与塑性，即细晶强化）：

1. **提高过冷度**：加快冷却速度、降低浇注温度。
2. **变质处理**：加入形核剂（孕育剂），促进非均匀形核。
3. **振动、搅拌**：机械振动、电磁搅拌、超声振动等，使枝晶破碎成为新晶核。

### 例题
题目：铸锭的三个晶区（细晶区、柱状晶区、等轴晶区）是如何形成的？列举两种细化晶粒的方法。

**答案**：表面因激冷、过冷度大而形成细晶区；随后热量垂直模壁外散，晶粒沿反方向择优生长成柱状晶；心部散热慢且杂质富集、形核多，形成中心等轴晶。细化晶粒方法：提高过冷度、变质处理、振动搅拌等。

## 【计算】临界晶核半径与临界形核功
- 章节：第6章 单组元相图及纯晶体的凝固
- 难度：较难
- 考点频率：高频

### 内容
均匀形核时，形成球形晶核使体系自由能变化为：

**ΔG = (4/3)πr³ΔGv + 4πr²σ**

其中 ΔGv 为液→固单位体积自由能差（ΔGv = −LmΔT/Tm，负值，是驱动力），σ 为固-液界面能（正值，是阻力）。小晶核表面能占优、不能长大；令 dΔG/dr = 0 得临界量：

**r\* = −2σ/ΔGv = 2σTm/(LmΔT)**

**ΔG\* = 16πσ³/(3ΔGv²) = 16πσ³Tm²/(3Lm²ΔT²)**

计算步骤：

1. 由过冷度算体积驱动力：|ΔGv| = LmΔT/Tm；
2. 代入 r\* = 2σ/|ΔGv|，注意 σ 取 J/m²、Lm 取 J/m³，算出的半径单位为 m，可换算成 nm；
3. 代入 ΔG\* = 16πσ³/(3ΔGv²)，得到 J/个（每个临界晶核的形核功），也可换算成 eV（1 eV ≈ 1.6×10⁻¹⁹ J）便于与 kT 比较。

结论：过冷度 ΔT 越大，|ΔGv| 越大，**r\* 与 ΔT 成反比、ΔG\* 与 ΔT² 成反比**，形核越容易、晶粒越细。

### 例题
某金属熔点 Tm = 1000 K，熔化潜热 Lm = 2×10⁹ J/m³，固-液界面能 σ = 0.2 J/m²。求过冷度 ΔT = 100 K 时均匀形核的临界晶核半径 r\* 与临界形核功 ΔG\*，并说明 ΔT 增大到 200 K 时二者如何变化。

**答案**：ΔT = 100 K 时 |ΔGv| = LmΔT/Tm = 2×10⁹×100/1000 = 2×10⁸ J/m³。r\* = 2σ/|ΔGv| = 2×0.2/(2×10⁸) = 2×10⁻⁹ m = 2 nm。ΔG\* = 16πσ³/(3ΔGv²) = 16π×0.008/(3×(2×10⁸)²) = 0.402/(1.2×10¹⁷) ≈ 3.35×10⁻¹⁸ J。当 ΔT 增大到 200 K 时，|ΔGv| 加倍为 4×10⁸ J/m³，r\* 减半为 1 nm，ΔG\* 降为 1/4（≈ 0.84×10⁻¹⁸ J）。即过冷度越大，临界晶核半径与临界形核功越小，形核越容易。
