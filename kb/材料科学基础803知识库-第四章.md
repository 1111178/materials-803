# 第四章 固体中原子及分子的运动（扩散）

---

## 扩散概述与菲克第一定律
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：基础
- 考点频率：高频

### 内容
**扩散**是固体中原子（或分子）在热运动驱动下从高浓度区向低浓度区迁移的宏观过程，是材料热处理、烧结、相变、渗碳氮化等的理论基础。

**菲克第一定律**描述稳态扩散（浓度分布不随时间变化）时扩散通量与浓度梯度的关系：

**J = −D · (dc/dx)**

其中 J 为扩散通量（单位时间通过单位面积的物质质量，单位 kg/(m²·s)），D 为扩散系数（m²/s），dc/dx 为浓度梯度（沿 x 方向的浓度变化率）。负号表示扩散沿浓度降低的方向进行（下坡扩散）。

例如，碳在钢表面渗碳时，表层碳浓度高、内部低，碳原子沿浓度梯度向内扩散。

### 例题
某稳态扩散中，沿 x 方向浓度梯度 dc/dx = −10 kg/m⁴，扩散系数 D = 2×10⁻¹¹ m²/s，求扩散通量 J。

**答案**：J = −D·(dc/dx) = −(2×10⁻¹¹)×(−10) = 2×10⁻¹⁰ kg/(m²·s)，方向沿 x 正方向。

## 菲克第二定律
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：高频

### 内容
**菲克第二定律**描述非稳态扩散（浓度随时间和位置都变化）的规律：

**∂c/∂t = D · (∂²c/∂x²)**

其含义是：某处浓度随时间的变化率，正比于该处浓度梯度的变化率（浓度的二阶导数）。

在给定初始条件和边界条件后，可解出浓度分布 c(x,t)。最常见的是**无限长固体**或**半无限长固体**的表面扩散问题，其解用**误差函数 erf** 表示，例如渗碳时：

**C(x,t) = Cs − (Cs − C₀)·erf[x/(2√(Dt))]**

其中 Cs 为表面浓度，C₀ 为初始浓度。这是工业渗碳、渗氮工艺计算渗层厚度和时间的基础。

### 例题
菲克第二定律描述的是什么过程？它与第一定律的区别是什么？

**答案**：菲克第二定律描述**非稳态扩散**（浓度随时间变化）的规律，∂c/∂t = D·∂²c/∂x²；菲克第一定律描述**稳态扩散**（浓度不随时间变化），J = −D·dc/dx。第二定律用于求解浓度随位置和时间的变化，是渗碳等工艺计算的基础。

## 扩散的热力学分析
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：较难
- 考点频率：中频

### 内容
菲克定律表明扩散沿浓度降低方向进行，但扩散的真正**驱动力不是浓度梯度，而是化学势梯度**。

由热力学可知，扩散沿化学势 μ 降低的方向进行，扩散通量正比于化学势梯度：

**J ∝ −(∂μ/∂x)**

当化学势梯度与浓度梯度方向相反时，就会出现**上坡扩散**（逆浓度梯度扩散，原子从低浓度区向高浓度区迁移）。典型例子：

- 碳钢中，C 从低浓度区向高浓度的**渗碳体（Fe₃C）**处扩散、聚集长大；
- 奥氏体中，Si 使 C 的化学势升高，C 向 Si 含量低处扩散（即向碳浓度高处），形成上坡扩散。

热力学判断扩散方向的标准是**化学势（或活度）梯度**，而非单纯的浓度梯度。当化学势均匀（∂μ/∂x = 0）时，即使浓度不均，扩散也达到动态平衡。

### 例题
什么是上坡扩散？举一个例子。

**答案**：上坡扩散是原子沿化学势降低方向、但逆浓度梯度进行的扩散。例如碳钢中碳从低浓度区向高浓度的渗碳体处聚集长大，即属上坡扩散。

## 扩散的原子机制
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：基础
- 考点频率：高频

### 内容
扩散的微观本质是原子在晶体中的**随机跳动**，主要机制有：

1. **间隙机制**：小原子（如 C、N、H）从晶格的一个间隙位置跳到相邻间隙位置。由于间隙位置多、所需能量低，间隙扩散速度快（如 C 在 Fe 中的扩散）。
2. **空位机制**：原子跳入相邻的空位中，相当于空位反向移动。这是置换固溶体、自扩散的主要机制。需要邻近存在空位，扩散较慢，且空位浓度随温度升高而增大。
3. **交换机制**：相邻两个原子直接交换位置，需要很大的晶格畸变能，实际很难发生；还有**环形换位机制**（多个原子协同转动），也因能量高而不常见。

间隙机制比空位机制快得多，因此间隙溶质（C、N）在钢中的扩散远比置换溶质（如合金元素 Cr、Ni）快。

### 例题
为什么碳在铁中的扩散比铬在铁中的扩散快得多？

**答案**：碳是间隙原子，通过间隙机制扩散，间隙位置多、迁移能量低，扩散快；铬是置换原子，通过空位机制扩散，需依赖空位且迁移能量高，扩散慢。

## 扩散激活能与阿伦尼乌斯方程
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：高频

### 内容
扩散系数 D 随温度呈指数关系变化，符合**阿伦尼乌斯方程**：

**D = D₀ · exp(−Q/RT)**

其中 D₀ 为频率因子（与晶体结构、振动频率等有关），Q 为**扩散激活能**（J/mol 或 kJ/mol），R 为气体常数（8.314 J/(mol·K)），T 为热力学温度（K）。

对式子取对数得：

**ln D = ln D₀ − Q/RT**

**扩散激活能 Q** 表示原子完成一次迁移所需克服的能垒，它包含原子的**迁移能**和（空位机制中）**空位形成能**。Q 越大，扩散越困难、D 越小；温度越高，D 越大。

利用两个温度下的 D 值可求激活能：ln(D₁/D₂) = (Q/R)·(1/T₂ − 1/T₁)。

### 例题
扩散系数随温度升高如何变化？为什么？

**答案**：扩散系数随温度升高而指数增大，因为 D = D₀·exp(−Q/RT)，温度升高使 exp(−Q/RT) 急剧增大。温度升高还使空位浓度增大，进一步促进扩散。

## 无规则行走与扩散距离
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：中频

### 内容
原子在晶体中的跳动是**无规则（随机）**的，每个原子的运动轨迹像"随机行走"。虽然单次跳动的方向是随机的，但大量原子统计上表现为宏观定向扩散。

原子无规则行走时，其**平均位移为零**，但**均方根位移**不为零，与时间、扩散系数有关：

**x = √(2Dt)**（一维）或 **x = √(6Dt)**（三维）

一般用 **x ≈ √(Dt)** 表示扩散距离的数量级。

这个关系有重要工程意义：扩散距离与时间的**平方根**成正比，与扩散系数的平方根成正比。即扩散时间增加到 4 倍，扩散距离只增加 2 倍；这就是为什么高温长时间渗碳才能得到足够深的渗层。

### 例题
已知某扩散过程 D = 1×10⁻¹⁵ m²/s，求经过 1 小时（3600 s）后原子的平均扩散距离（量级）。

**答案**：x ≈ √(Dt) = √(1×10⁻¹⁵ × 3600) = √(3.6×10⁻¹²) ≈ 1.9×10⁻⁶ m = 1.9 μm。

## 影响扩散的因素
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：高频

### 内容
影响扩散系数和扩散速度的主要因素：

1. **温度**：影响最大，D = D₀·exp(−Q/RT)，温度升高扩散急剧加快。
2. **晶体结构**：致密度低的结构扩散快。如 BCC 的 α-Fe 致密度（0.68）低于 FCC 的 γ-Fe（0.74），故 C 在 α-Fe 中的扩散系数远大于在 γ-Fe 中。
3. **固溶体类型**：间隙溶质扩散比置换溶质快得多。
4. **浓度**：D 一般随浓度变化（组元间结合力影响）。
5. **晶体缺陷（短路扩散）**：晶界、位错、表面处原子排列疏松，扩散快。**表面扩散 > 晶界扩散 > 位错（管道）扩散 > 体（晶格）扩散**。低温下短路扩散贡献大。
6. **第三组元**：某些合金元素可加速或减慢扩散（如钢中加 Co 加速 C 扩散，加 Mn、Cr 等减慢）。

### 例题
为什么碳在体心立方的 α-Fe 中扩散比在面心立方的 γ-Fe 中快？

**答案**：BCC 的致密度（0.68）低于 FCC（0.74），α-Fe 中原子排列较疏松、间隙较大，碳原子迁移能垒较低，故扩散系数大、扩散快。

## 反应扩散
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：基础
- 考点频率：中频

### 内容
**反应扩散（相变扩散）**是指在扩散过程中，扩散组元与基体反应、在界面处**生成新相（化合物）**的扩散过程。与单纯扩散不同，反应扩散伴随新相的形核与长大，扩散的同时发生化学反应。

典型例子：

- **渗碳**：碳原子渗入钢表面，超过奥氏体溶碳极限后析出 Fe₃C（渗碳体），表面形成碳化物层；
- **渗氮**：氮与铁、合金元素生成 Fe₂N、Fe₄N 等氮化物；
- **热浸镀铝、渗硼、渗金属**等表面强化工艺。

反应扩散的规律：扩散层中新相的组织分布由**相图**决定，按浓度梯度依次出现相图中相邻的相；新相长大速度由扩散控制，层厚与时间成抛物线关系（x ∝ √t）。

### 例题
什么是反应扩散？它与普通扩散的根本区别是什么？

**答案**：反应扩散是扩散过程中在界面生成新相（化合物）的扩散，如渗碳时生成 Fe₃C。与普通扩散的区别在于：反应扩散伴随新相的形核长大和化学反应，扩散层中新相按相图规律分布。

## 离子晶体中的扩散（无机非考点）
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：中频

### 内容
离子晶体（如 NaCl、MgO、陶瓷）中的扩散与金属不同，具有以下特点：

1. **主要通过空位机制**进行，正离子和负离子各自沿自己的子晶格空位迁移。
2. **必须保持电中性**：正、负离子不能各自独立地任意扩散，否则会造成局部电荷积累。因此扩散常以"**肖特基缺陷对**"（正负离子空位对）或"**弗仑克尔缺陷**"（空位+间隙离子）的形式协同进行。
3. **扩散系数小**：离子键强、迁移能垒高，扩散比金属慢得多，通常要在很高温度（接近熔点）才显著。
4. **本征扩散与非本征扩散**：高温下由热激活产生的空位（本征缺陷）主导，低温下由杂质引入的空位（非本征缺陷）主导。

离子晶体中的扩散是陶瓷烧结、固相反应、导电（离子导体如 ZrO₂ 中 O²⁻ 迁移）的基础。

### 例题
离子晶体中的扩散为什么通常比金属慢？

**答案**：离子晶体靠空位机制扩散，且正负离子须成对（肖特基缺陷对或弗仑克尔缺陷）协同迁移以保持电中性；离子键强、迁移能垒高，故扩散慢，通常需在高温下才显著。

## 高分子的分子运动
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：基础
- 考点频率：低频

### 内容
高分子的分子运动比小分子复杂得多，按运动单元分为几个层次：

1. **链段运动**：高分子链中几个~几十个链节组成的"链段"作为独立运动单元发生旋转、位移，是高分子最基本的运动形式。
2. **整链运动**：整个高分子链作为整体发生重心移动（流动），发生在黏流温度 Tf 以上。
3. **侧基、支链及小单元运动**：比链段更小的局部运动。

高分子运动具有明显的**温度依赖性**，从而表现出三个特征温度：

- **玻璃化转变温度 Tg**：链段开始运动的温度，低于 Tg 时高分子处于玻璃态（硬脆），高于 Tg 时进入高弹态。
- **黏流温度 Tf**：整链开始流动的温度，高于 Tf 时进入黏流态（可加工成型）。

高分子的扩散（小分子在聚合物中渗透、高分子自扩散）与链段运动密切相关，速度远比金属和离子晶体慢。

### 例题
什么是玻璃化转变温度 Tg？它在高分子材料中有什么意义？

**答案**：Tg 是高分子链段开始运动的温度。低于 Tg 时材料处于玻璃态（硬而脆），高于 Tg 时进入高弹态（柔软有弹性）。Tg 是高分子使用温度上限（对塑料）或下限（对橡胶）的重要依据。

## 柯肯达尔效应
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：中频

### 内容
**柯肯达尔效应**是置换固溶体中两组元**扩散系数不等**导致的界面移动现象。

实验：在纯金属 A 和 B 之间放置惰性标记（如细钼丝），高温扩散退火后发现**标记面向扩散慢的一侧移动**。这表明两组元的扩散速度不同，异种原子通过**空位机制**扩散（而非直接交换机制）。

柯肯达尔效应的意义：

1. 证明置换固溶体中的扩散主要通过**空位机制**进行；
2. 说明不同组元的**扩散系数不等**（D_A ≠ D_B）；
3. 由于原子流与空位流方向相反，扩散慢的一侧会累积空位，超过平衡浓度时形成**柯肯达尔空洞（孔隙）**，是扩散焊、金属间化合物界面常见缺陷的原因。

### 例题
柯肯达尔效应证明了什么？它可能导致什么缺陷？

**答案**：柯肯达尔效应（标记面移动）证明置换扩散通过空位机制进行、且两组元扩散系数不等。由于空位流与原子流反向，扩散慢的一侧空位过饱和，可能形成柯肯达尔空洞（孔隙）。

## 扩散系数计算
- 章节：第4章 固体中原子及分子的运动（扩散）
- 难度：中等
- 考点频率：高频

### 内容
**公式**（阿伦尼乌斯方程）：**D = D₀ · exp(−Q/RT)**

**符号含义**：
- D：扩散系数（m²/s）
- D₀：频率因子（扩散常数），与晶体结构、振动频率有关
- Q：扩散激活能（J/mol，注意单位换算：1 kJ/mol = 1000 J/mol）
- R：气体常数 = 8.314 J/(mol·K)
- T：热力学温度（K）

**常用变形**（由两个温度下的 D 求激活能）：**ln(D₁/D₂) = (Q/R)·(1/T₂ − 1/T₁)**

温度升高，D 按指数规律急剧增大；激活能 Q 越大，扩散越困难。

### 例题
题目：已知某扩散过程 D₀ = 5×10⁻⁵ m²/s，激活能 Q = 83.14 kJ/mol，求 T = 1000 K 时的扩散系数 D。

**已知**：D₀ = 5×10⁻⁵ m²/s，Q = 83140 J/mol，T = 1000 K，R = 8.314 J/(mol·K)。
**公式**：D = D₀·exp(−Q/RT)。
**代入**：Q/RT = 83140/(8.314×1000) = 83140/8314 = 10，故 −Q/RT = −10；exp(−10) ≈ 4.54×10⁻⁵，所以 D = 5×10⁻⁵ × 4.54×10⁻⁵ = 2.27×10⁻⁹。
**结果**：D ≈ 2.27×10⁻⁹ m²/s。
题目：测得某扩散过程 1000 K 时 D₁ = 1×10⁻¹⁴ m²/s、1200 K 时 D₂ = 1×10⁻¹² m²/s，求扩散激活能 Q。
**已知**：D₁、D₂ 及对应温度 T₁ = 1000 K、T₂ = 1200 K，R = 8.314 J/(mol·K)。
**公式**：ln(D₂/D₁) = (Q/R)·(1/T₁ − 1/T₂)。
**代入**：Q = R·ln(D₂/D₁)/(1/T₁ − 1/T₂) = 8.314 × ln(100)/(1/1000 − 1/1200) ≈ 230 kJ/mol。
**结果**：Q ≈ 230 kJ/mol。

题目：某碳钢渗碳，表面碳浓度 0.9%，距表面 0.5 mm 处为 0.4%，扩散系数 D = 3×10⁻¹¹ m²/s，钢密度 ρ = 7800 kg/m³。近似按稳态用菲克第一定律求扩散通量 J。
**已知**：Δw = 0.9%−0.4% = 0.005，Δx = 0.5 mm = 5×10⁻⁴ m，D = 3×10⁻¹¹ m²/s。
**公式**：J = −D·(dC/dx)，其中 ΔC = ρ·Δw。
**代入**：ΔC = 7800×0.005 = 39 kg/m³；dC/dx ≈ 39/(5×10⁻⁴) = 78000 kg/m⁴；J = 3×10⁻¹¹×78000 ≈ 2.34e-06 kg·m⁻²·s⁻¹。
**结果**：J ≈ 2.3×10⁻⁶ kg·m⁻²·s⁻¹。
