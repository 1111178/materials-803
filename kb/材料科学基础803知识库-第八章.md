# 第八章 三元相图

## 成分三角形
- 章节：第8章 三元相图
- 难度：基础
- 考点频率：中频

### 内容
三元合金含三个组元 A、B、C，其成分需用**等边三角形（成分三角形）**表示。

规则：

- 三个**顶点**分别代表纯组元 A、B、C（含量 100%）。
- 三条**边**代表相应的二元合金。
- 三角形**内部任一点**代表一个三元合金。

确定某点成分的方法是：过该点作三边（或过该点分别作三边中两条边的平行线）的平行线，按截距读出各边对应的组元含量。常用**平行线法**：过点作与三边分别平行的直线，它们在三条边上截出的长度即对应顶点组元的含量，且三组元含量之和恒等于 100%。

例如三角形内部越靠近顶点 A 的点，A 含量越高；位于三角形正中心的点，三组元各占约 33.3%。

### 例题
三元合金成分三角形中，某合金点恰好位于三角形几何中心，三组元含量各是多少？

**答案**：各约 33.3%（A、B、C 各占 1/3），因为等边三角形中心到三边等距。

## 三元相图中的杠杆定律与重心法则
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：高频

### 内容
三元相图中有两条重要的定量计算法则：

**1. 直线法则（杠杆定律）**：处于两相平衡时，合金的成分点与两相的成分点必在**同一条直线上**，且合金点位于两相点之间。两相相对量按**杠杆定律**计算：

**W₁ / W₂ = (OP₂) / (OP₁)**（P 为合金点，P₁、P₂ 为两相点，用量与到合金点距离成反比）。

**2. 重心法则**：三相平衡时，三个相的成分点构成一个三角形（**连接三角形**），合金成分点必在该三角形内，三相相对量由**重心法则**确定：将合金点与三相点两两连线，把三角形分成三个小三角形，各相的质量分数与该相对顶点的小三角形**面积成正比**：

**Wᵢ = Sᵢ / S总**（Sᵢ 为与相 i 相对的小三角形面积）。

### 例题
三元相图中三相平衡时，如何确定三个相的相对量？

**答案**：用重心法则。三相成分点构成连接三角形，合金点位于其中，连接合金点与三个相点，将三角形分成三个小三角形，各相质量分数与其相对顶点的小三角形面积成正比。

## 固态互不溶解的三元共晶相图
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：中频

### 内容
当 A、B、C 三组元在**液态无限互溶、固态完全互不溶解**时，形成三元共晶相图，其核心是**三元共晶反应**：

**L → A + B + C**

这一反应在**四相平衡**（一个液相 + 三个固相）下进行，由相律 f = 3 − 4 + 1 = 0（恒压），在**恒温**下进行，对应一个确定的共晶成分点（三元共晶点）和一条水平截面。

相图的主要区域：

- **液相区**（高温单相区）。
- **两相区**：L + A、L + B、L + C（液相与一个固相共存）。
- **三相区**：L + A + B、L + B + C、L + C + A（液相与两个固相共存）。
- **四相平衡点**：L + A + B + C 三元共晶点。
- 低温区：A + B + C 三个固相。

分析凝固路径时，从液相出发，依次经过两相区（先析出某一纯组元）、三相区（发生二元共晶），最后到三元共晶点完成凝固，组织为**初晶 + 二元共晶 + 三元共晶**。

### 例题
三元共晶反应 L → A + B + C 为什么在恒温下进行？

**答案**：三元共晶时四相共存（L、A、B、C），由相律 f = C − P + 1 = 3 − 4 + 1 = 0，自由度为 0，故在恒温下进行。

## 固态有限互溶的三元共晶相图
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：低频

### 内容
当三组元液态互溶、固态**有限互溶**时，相图中出现固溶体单相区 α、β、γ（分别以 A、B、C 为溶剂）。相图结构与固态互不溶解的三元共晶类似，但更为复杂：

- 存在三个**固溶体单相区** α、β、γ（靠近三个顶点）。
- 存在固溶体之间的**两相区** α + β、β + γ、γ + α。
- 三元共晶反应变为：**L → α + β + γ**（四相平衡、恒温）。
- 固溶体 α 随温度降低，溶解度（固溶度）减小，会析出第二相（类似固态脱溶）。

分析这类相图时，需要区分液相凝固过程和固态冷却时的脱溶过程，是三元相图中最复杂的情形。

### 例题
固态有限互溶的三元共晶相图与固态互不溶解的三元共晶相图相比，多了哪些区域？

**答案**：多了固溶体单相区（α、β、γ）和固溶体之间的两相区（α+β、β+γ、γ+α），共晶反应产物由纯组元变为固溶体（L → α + β + γ）。

## 三元相图小结
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：低频

### 内容
三元相图类型多样，除共晶外还有**三元匀晶相图**（三组元固态无限互溶）、含**中间化合物**的三元相图等。分析三元相图的一般方法：

1. **确定单相区、两相区、三相区、四相平衡点**，判明各相区的相组成。
2. **判明四相平衡反应类型**（共晶 L → α+β+γ，包共晶 L+α → β+γ，包晶 L+α+β → γ 等），由相律知这些反应均恒温进行。
3. 借助**等温截面图**（水平截面）和**垂直截面图**（变温截面）分析具体成分合金的凝固路径。
4. 用**杠杆定律（两相）**和**重心法则（三相）**计算相和组织组成物的相对量。

三元相图的实际应用：分析合金钢、耐热合金、陶瓷（三元氧化物）的相组成与组织，为成分设计和热处理提供依据。

### 例题
分析一个三元合金的凝固过程，一般需要借助哪些截面图？分别解决什么问题？

**答案**：借助等温截面图（水平截面）了解某一温度下各相区及相组成，借助垂直截面图（变温截面）分析合金在冷却过程中的相变路径；再配合杠杆定律、重心法则计算各相相对量。

## 三元相图的空间模型与投影图
- 章节：第8章 三元相图
- 难度：基础
- 考点频率：中频

### 内容
三元系自由度为 3（恒压下为 2），成分需两个独立变量表示，故完整的三元相图是**以温度与两个成分为坐标的立体图**，通常画成**三棱柱体**：

- **底面**是成分三角形（浓度三角形）：三个顶点分别代表纯组元 A、B、C，三条边分别表示 A-B、B-C、C-A 三个二元系。
- **纵轴**表示温度；三棱柱的**三个侧面**恰好是 A-B、B-C、C-A 三个二元相图沿温度竖立起来的图形。
- 柱体内部由若干**曲面**把空间划分成单相区、两相区与三相区。以三元共晶系为例：三个初晶（A、B、C）的液相面相互交成三条**沟线（单变量线）**，沟线向下汇于**三元共晶点 E**（四相平衡、恒温），E 之下是三相共晶固相面，再往下为三个固相。
- 立体图不便于测量与书写，实用中把关键信息**投影到底面成分三角形**上形成**投影图**（标出各初晶区边界、单变量线、共晶点及等温线），并辅以**等温截面**与**垂直截面**来具体读图。

所以掌握三元相图的顺序是：先看懂三个侧面（二元相图），再看内部曲面与沟线，最后学会在投影图与截面上分析具体合金。

### 例题
三元相图的立体模型由哪些部分组成？三个侧面与三个二元相图是什么关系？

**答案**：模型是底面为成分三角形、纵轴为温度的三棱柱；三个侧面分别是以 A-B、B-C、C-A 为成分轴、沿温度方向展开的相应二元相图，因此看懂对应二元系是读三元相图的基础。柱体内部由液相面、固相面等曲面以及沟线（单变量线）、四相平衡点把空间分为各相区。

## 等温截面与垂直截面（变温截面）
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：高频

### 内容
三元立体相图不方便直接使用，实际分析靠两类"切片"：

**等温截面（水平截面）**：在某一固定温度下水平切开相图。用途：
- 直接读出该温度下存在哪些**相区**；
- **单相区**是一整块区域；**两相区**内用**连接线（结线）**连接两平衡相的成分点，可据**杠杆定律**算两相相对量；
- **三相区**呈**连接三角形**，三个顶点即三个平衡相的成分，合金点位于三角形内时用**重心法则**算各相相对量；
- 比较不同温度的等温截面可追踪相区随温度的演化。

**垂直截面（变温截面）**：固定某一成分关系（如 C 含量固定、或 A:B 比例固定）沿竖直面切开，横轴是成分、纵轴是温度。用途：
- 反映某一类成分合金**冷却/加热过程中的相变温度与相变顺序**，可以读出开始凝固线与凝固终了线，形式像"伪二元相图"；
- 局限：它不是真正的二元相图，截面内两相区的**结线一般不在该截面内**，故**不能直接使用杠杆定律**求相成分与相对量；三相平衡（如二元共晶平台）在垂直截面上表现为一段水平线。

### 例题
为什么垂直截面（变温截面）不能像二元相图那样直接使用杠杆定律？

**答案**：在二元相图中，两相平衡的结线必然落在该成分-温度平面内，可在图上直接取两相成分并用力矩关系计算相对量；而在三元系的垂直截面上，真实的两相结线一般不落在该截面内，两平衡相的成分点并不在截面上，因此无法用杠杆定律定量。垂直截面只用来判断相变温度与相变过程；要求相成分与相对量，须用等温截面（结线在水平面内）或投影图配合重心法则。

## 三元匀晶相图
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：低频

### 内容
A、B、C 三组元在**液态与固态均无限互溶**时形成**三元匀晶相图**（空间上只有一个固溶体相 α，如某些完全互溶的三元固溶体系）。

- 空间图形有两个曲面：**液相面**（之上全部为液相）与**固相面**（之下全部为 α 固溶体），两曲面之间是 **L + α 两相区**。
- 任意成分合金在液相面之上为液态；冷到液相面开始析出 α；冷到固相面凝固完毕，得到成分均匀的 α。

**平衡凝固过程**：随温度下降，液相成分沿液相面变化、固相成分沿固相面变化，二者始终由**结线**相连以保持平衡，最终固相的平均成分即合金原始成分。凝固过程中原子须通过扩散重新分配，冷却较快时扩散来不及进行，先析出与后析出的固相成分不同，会形成**枝晶偏析（晶内偏析）**，需扩散退火消除，这与二元固溶体凝固完全类似，只是成分自由度高了一个维度。

### 例题
三元匀晶合金平衡凝固时，液相与固相的成分分别如何变化？最终固相的平均成分是什么？

**答案**：冷却到液相面时开始结晶出 α；随温度继续降低，液相成分沿液相面移动、固相成分沿固相面移动，两相始终保持平衡并用结线相连；当温度降到固相面、最后一滴液相耗尽时凝固结束，最终固相的平均成分等于合金的原始成分。若冷却过快则扩散来不及，会出现枝晶偏析。

## 单变量线（沟线）与三相平衡区
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：中频

### 内容
三元共晶系中，三个初晶相（A、B、C）的液相面两两相交，交线在空间自上而下延伸，其投影称为**单变量线（沟线）**。单变量线是分析三元相图的关键：

- 在单变量线上，液相与两个固相三相共存，发生**二元共晶反应 L → A + B**。由相律（恒压）**f = C − P + 1 = 3 − 3 + 1 = 1**，有 1 个自由度，故反应在**一个温度区间内连续进行**：温度与液相成分都沿单变量线同步下降。这与二元相图中的共晶（自由度 0、恒温）不同——三元系里的"二元共晶"是**一条线**，而不是一个等温平台。
- 三条单变量线在低温汇于**三元共晶点 E**（四相平衡 L + A + B + C），此时 **f = 3 − 4 + 1 = 0**，凝固在**恒温**下进行，得到 (A+B+C) 三元共晶。
- **三相平衡区**是一个空间"棱柱带"：位于两个相邻的两相区之间，其三个边界分别与 L+A、L+B、A+B 等两相区相邻；合金成分一旦进入该区就发生二元共晶。
- 在投影图上，单变量线把成分三角形划分成三个**初晶区**，据此可判断任意成分合金先析出哪一相。

### 例题
为什么三元共晶系中的二元共晶反应沿一条线进行、而不是像二元相图中那样在恒温下进行？

**答案**：二元共晶反应 L → A + B 在三元系中属于三相平衡（液相 + 两个固相），恒压相律 f = C − P + 1 = 3 − 3 + 1 = 1，自由度为 1，因此温度与液相成分可沿单变量线连续变化，反应在温度区间内完成；而三元共晶 L → A + B + C 是四相平衡，f = 3 − 4 + 1 = 0，自由度为零，才在固定的三元共晶点恒温进行。

## 三元包共晶与包晶反应
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：中频

### 内容
三元系中的四相平衡反应除共晶外还有两类，由相律 **f = C − P + 1 = 3 − 4 + 1 = 0**，它们都**在恒温下**进行。三类反应的区别在反应式两侧固相个数：

1. **三元共晶反应**：**L → α + β + γ**。一个液相分解为三个固相，无固相参加反应。
2. **三元包共晶反应**：**L + α → β + γ**。一个液相与一个固相 α 反应，生成两个新固相 β、γ（介于共晶与包晶之间，故称"包共晶"）。
3. **三元包晶反应**：**L + α + β → γ**。一个液相与两个固相反应，生成第三个固相 γ。

包共晶与包晶的共同特点是：新相（β、γ 或 γ）在原有固相表面**包覆式**生成，后续反应必须靠原子**扩散穿过新相层**才能继续，因此这类反应往往**进行不完全**，凝固组织中易保留残留液相转变的产物或出现成分偏析，实际合金需借助热处理改善。

记忆技巧：**数反应物中的固相个数**——共晶 0 个、包共晶 1 个、包晶 2 个（"包"字越多，参加反应的固相越多）。

### 例题
如何区分三元系中共晶、包共晶与包晶三类四相平衡反应？它们的共同特征是什么？

**答案**：按反应式中固相反应物的个数区分：无固相反应物为共晶 L → α + β + γ；有一个固相反应物为包共晶 L + α → β + γ；有两个固相反应物为包晶 L + α + β → γ。三者均为四相平衡，恒压相律自由度 f = 0，都必然在恒温下进行。

## 三元共晶合金的凝固路径与组织分析
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：高频

### 内容
以三组元固态互不溶解的三元共晶系（L → A + B + C）为例，分析某成分合金的凝固路径，关键是看合金成分点在**投影图**上的位置：

1. **判断初晶区**：投影图被三条单变量线（沟线）分成 A、B、C 三个初晶区。成分点落在哪个初晶区，冷却到该组元的液相面时即先析出相应**初晶**（如落 A 区先析 A），进入 L + A 两相区。
2. **到达单变量线（二元共晶线）**：随温度下降、初晶不断析出，剩余液相成分点移动到沟线 e₁E 时，发生**二元共晶 L → A + B**，反应在温度区间内沿沟线向 E 进行。
3. **到达三元共晶点 E**：剩余液相成分变为 E，发生**三元共晶 L → (A+B+C)**，在恒温下凝固完毕。室温组织为：

**初晶 A + 二元共晶(A+B) + 三元共晶(A+B+C)**

若合金成分恰落在单变量线或三元共晶点上，则可跳过初晶或二元共晶阶段，组织相应简化（共晶成分只得到三元共晶组织）。各组成物的相对量可在投影图上用面积/重心关系分段估算；室温下相组成物仍是 A、B、C，可按总成分用杠杆定律求出三者的质量分数。

### 例题
某三元共晶合金的成分点落在投影图的 A 初晶区、且靠近单变量线，写出它平衡凝固的路径与最终室温组织。

**答案**：冷却到 A 的液相面后先析出初晶 A，液相成分沿液相面变化；到达单变量线后发生二元共晶 L → A + B（在温度区间内进行，液相成分沿沟线移向三元共晶点 E）；剩余液相到达 E 后发生三元共晶 L → (A+B+C)，恒温凝固完毕。最终室温组织为：初晶 A + 二元共晶(A+B) + 三元共晶(A+B+C)。
