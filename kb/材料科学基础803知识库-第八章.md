# 第八章 三元相图

---

## 成分三角形
- 章节：第8章 三元相图
- 难度：基础
- 考点频率：中频

### 内容
三元合金含三个组元 A、B、C，其成分需用**等边三角形（成分三角形）**表示。

规则：

- 三个**顶点**分别代表纯组元 A、B、C（含量 100%）。
- 三条**边**代表相应的二元合金。
- 三角形**内部任一点**代表一个三元合金。

确定某点成分的方法是：过该点作三边（或过该点分别作三边中两条边的平行线）的平行线，按截距读出各边对应的组元含量。常用**平行线法**：过点作与三边分别平行的直线，它们在三条边上截出的长度即对应顶点组元的含量，且三组元含量之和恒等于 100%。

例如三角形内部越靠近顶点 A 的点，A 含量越高；位于三角形正中心的点，三组元各占约 33.3%。

### 例题
三元合金成分三角形中，某合金点恰好位于三角形几何中心，三组元含量各是多少？

**答案**：各约 33.3%（A、B、C 各占 1/3），因为等边三角形中心到三边等距。

## 三元相图中的杠杆定律与重心法则
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：高频

### 内容
三元相图中有两条重要的定量计算法则：

**1. 直线法则（杠杆定律）**：处于两相平衡时，合金的成分点与两相的成分点必在**同一条直线上**，且合金点位于两相点之间。两相相对量按**杠杆定律**计算：

**W₁ / W₂ = (OP₂) / (OP₁)**（P 为合金点，P₁、P₂ 为两相点，用量与到合金点距离成反比）。

**2. 重心法则**：三相平衡时，三个相的成分点构成一个三角形（**连接三角形**），合金成分点必在该三角形内，三相相对量由**重心法则**确定：将合金点与三相点两两连线，把三角形分成三个小三角形，各相的质量分数与该相对顶点的小三角形**面积成正比**：

**Wᵢ = Sᵢ / S总**（Sᵢ 为与相 i 相对的小三角形面积）。

### 例题
三元相图中三相平衡时，如何确定三个相的相对量？

**答案**：用重心法则。三相成分点构成连接三角形，合金点位于其中，连接合金点与三个相点，将三角形分成三个小三角形，各相质量分数与其相对顶点的小三角形面积成正比。

## 固态互不溶解的三元共晶相图
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：中频

### 内容
当 A、B、C 三组元在**液态无限互溶、固态完全互不溶解**时，形成三元共晶相图，其核心是**三元共晶反应**：

**L → A + B + C**

这一反应在**四相平衡**（一个液相 + 三个固相）下进行，由相律 f = 3 − 4 + 1 = 0（恒压），在**恒温**下进行，对应一个确定的共晶成分点（三元共晶点）和一条水平截面。

相图的主要区域：

- **液相区**（高温单相区）。
- **两相区**：L + A、L + B、L + C（液相与一个固相共存）。
- **三相区**：L + A + B、L + B + C、L + C + A（液相与两个固相共存）。
- **四相平衡点**：L + A + B + C 三元共晶点。
- 低温区：A + B + C 三个固相。

分析凝固路径时，从液相出发，依次经过两相区（先析出某一纯组元）、三相区（发生二元共晶），最后到三元共晶点完成凝固，组织为**初晶 + 二元共晶 + 三元共晶**。

### 例题
三元共晶反应 L → A + B + C 为什么在恒温下进行？

**答案**：三元共晶时四相共存（L、A、B、C），由相律 f = C − P + 1 = 3 − 4 + 1 = 0，自由度为 0，故在恒温下进行。

## 固态有限互溶的三元共晶相图
- 章节：第8章 三元相图
- 难度：较难
- 考点频率：低频

### 内容
当三组元液态互溶、固态**有限互溶**时，相图中出现固溶体单相区 α、β、γ（分别以 A、B、C 为溶剂）。相图结构与固态互不溶解的三元共晶类似，但更为复杂：

- 存在三个**固溶体单相区** α、β、γ（靠近三个顶点）。
- 存在固溶体之间的**两相区** α + β、β + γ、γ + α。
- 三元共晶反应变为：**L → α + β + γ**（四相平衡、恒温）。
- 固溶体 α 随温度降低，溶解度（固溶度）减小，会析出第二相（类似固态脱溶）。

分析这类相图时，需要区分液相凝固过程和固态冷却时的脱溶过程，是三元相图中最复杂的情形。

### 例题
固态有限互溶的三元共晶相图与固态互不溶解的三元共晶相图相比，多了哪些区域？

**答案**：多了固溶体单相区（α、β、γ）和固溶体之间的两相区（α+β、β+γ、γ+α），共晶反应产物由纯组元变为固溶体（L → α + β + γ）。

## 三元相图小结
- 章节：第8章 三元相图
- 难度：中等
- 考点频率：低频

### 内容
三元相图类型多样，除共晶外还有**三元匀晶相图**（三组元固态无限互溶）、含**中间化合物**的三元相图等。分析三元相图的一般方法：

1. **确定单相区、两相区、三相区、四相平衡点**，判明各相区的相组成。
2. **判明四相平衡反应类型**（共晶 L → α+β+γ，包共晶 L+α → β+γ，包晶 L+α+β → γ 等），由相律知这些反应均恒温进行。
3. 借助**等温截面图**（水平截面）和**垂直截面图**（变温截面）分析具体成分合金的凝固路径。
4. 用**杠杆定律（两相）**和**重心法则（三相）**计算相和组织组成物的相对量。

三元相图的实际应用：分析合金钢、耐热合金、陶瓷（三元氧化物）的相组成与组织，为成分设计和热处理提供依据。

### 例题
分析一个三元合金的凝固过程，一般需要借助哪些截面图？分别解决什么问题？

**答案**：借助等温截面图（水平截面）了解某一温度下各相区及相组成，借助垂直截面图（变温截面）分析合金在冷却过程中的相变路径；再配合杠杆定律、重心法则计算各相相对量。
